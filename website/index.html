Download ErdOS

Build installers from source, or grab release artifacts once published to GitHub Releases.

Windows Installer (.exe) npm run dist:win → dist/ErdOS-Setup-*.exe
Linux AppImage npm run dist:linux → dist/ErdOS-*.AppImage
Linux Debian package npm run dist:linux → dist/ErdOS-*.deb

Build from source:

npm install
npm start          # run ErdOS
npm run dist:win   # Windows installer
npm run dist:linux # AppImage + deb
