A desktop inside a window.

ErdOS is an Electron app you install like any other. On Mac, Windows, or Linux it opens in its own window — your real desktop, Dock, and menu bar stay untouched.

Phosphor Glass UI

Chunky retro titlebars, CRT boot bloom, glass panels, and springy window motion.

Habit loops that respect you

Streaks, XP, quests, and rare wallpaper drops — delightful, local, no accounts or ads.

ERDAI onboard

Offline assistant with memory, fortunes, quest tips, and a personality that fits the desktop.

Built-in apps

Everything you need to explore, play, and customize without leaving ErdOS.

  • Browser — bookmarks, home page, webview browsing
  • ERDAI — desktop AI with memory and daily fortune
  • Arcade — Snake, Breakout, Memory, Pong + high scores
  • Terminal — CRT green/amber command line
  • Files & Notepad — local ErdOS home folders
  • Music Box · Sticky Notes · Trophy Case · Settings

Download ErdOS

Grab the latest public release. Builds are unsigned — on Windows choose More info → Run anyway; on Mac right-click the app → Open (or clear quarantine).

All assets on GitHub Releases →

Or build from source:

git clone https://github.com/ErdTheTurd/ERDOS.git
cd ERDOS
npm install
npm start
npm run dist:win   # Windows
npm run dist:mac   # macOS (DMG)
npm run dist:linux # AppImage + deb
